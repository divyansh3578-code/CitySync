# 🌆 CitySync – Intelligent Urban Complaint Routing

CitySync is an AI-powered platform that streamlines urban complaint management by automatically classifying, prioritizing, and routing citizen-reported issues to the appropriate authorities. It helps improve response time, transparency, and overall city governance.

---

## 🚀 Features

- 🧠 Smart Issue Classification using NLP
- 🧭 Intelligent Routing to correct departments
- 🚨 AI-based Priority Detection
- 🔁 Spam & Duplicate Complaint Detection
- 📊 Real-time Status Tracking Dashboard
- 🗺️ Geo-tagged Map Visualization
- 📱 WhatsApp & SMS Integration

---

## ⚙️ Tech Stack

- **Frontend:** React, Tailwind CSS  
- **Backend:** Node.js, Express  
- **AI/ML:** Python, FastAPI, Scikit-learn  
- **Database:** PostgreSQL (with PostGIS)  
- **Tools:** Docker, Twilio API  

---

## 🔄 Workflow

1. User submits complaint (text/image/location)  
2. AI classifies category & priority  
3. Complaint is routed to the correct department  
4. User tracks status in real time
